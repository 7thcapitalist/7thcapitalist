## Pinned Projects

These are the projects I would pin first, in order of importance:

1. **[OpenClaw Agents Headquarter](https://github.com/7thcapitalist/Openclaw-Agents-Headquarter)**

   A local command center for running AI agents like a small startup team. It connects OpenClaw with a browser HQ, separates conceptual personas from executable worker agents, tracks runs and outputs, and runs each worker through a constrained `run.sh` boundary.

   Stack: OpenClaw, Node.js, Express, SQLite, JSON state, PM2, systemd user services, Tailscale/private networking, mini PC.

2. **[Escola do Real Showcase](https://github.com/7thcapitalist/Escola-do-Real-showcase)**

   Public showcase for a private financial education app built for Brazilians. The product includes mobile-first lessons, a wallet/budget experience, written guides, an original book called **O Primeiro Real**, and recorded classes inside the platform.

   Stack: React Native, Expo, TypeScript, Supabase, Replit deployment, mobile production build tooling.

3. **[Spotify Playlist Skill](https://github.com/7thcapitalist/spotify-playlist-skill)**

   A TypeScript CLI and local Cursor/OpenClaw skill that turns natural-language prompts into real Spotify playlists. It handles artist extraction, similar-artist expansion, playlist balancing, explicit filtering, duplicate-release cleanup, and Spotify OAuth.

   Stack: TypeScript, Node.js, Spotify Web API, local OAuth, AI-backed prompt interpretation, tests.

4. **[Innovation as a Measure of Economic Growth](https://github.com/7thcapitalist/Innovation-as-a-measure-of-economic-growth)**

   Interactive data-storytelling project and regression paper exploring whether innovation helps explain differences in GDP per capita and long-run prosperity across countries.

   Stack: HTML, Bootstrap, Python visualizations, World Bank data, Global Innovation Index data, R&D expenditure datasets, GitHub Pages.
